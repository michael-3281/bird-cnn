Technical Deep Dive

This model uses a 4-layer Convolutional Neural Network (CNN). Here's the logic behind the predictions!

1. Feature Extraction (Convolution)

The model slices small "filters" over the image to detect raw patterns (e.g. the curve of a beak).

2. The Activation Switch (ReLU)

After each convolution, the ReLU function decides which features are important enough to pass forward, filtering out the "noise."

3. Probability Distribution (Softmax)

The final layer looks at all detected features and calculates a final probability score for every bird species in the database.
